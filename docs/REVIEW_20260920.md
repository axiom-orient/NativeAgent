## 1. 결론

**기존 패키지 경계를 유지하고, ChatGPT의 실제 완료 경로를 보강했다.** 전체를 한 manager나 umbrella package로 재설계하지 않았다. 실제 HTTP 종료 결속, 리다이렉트 race, 완료 대기 중 취소, 선택형 source 패키징을 수정했다.

**상용 준비 완료 판정은 아직 아니다.** Linux에서 common runtime과 실제 local URLSession을 검증했지만, full Apple Account/Text/Image 모듈과 native SDK/기기/실계정/ASK·MCP 전체 조합은 검증되지 않았다. 하위 wire 성공을 전체 서비스 성공으로 승계하지 않는다.

## 2. 입력·조사 범위

입력은 `NativeAI-Reviewed-20260920(1).zip`이다. ZIP 파일 1,673개, 자체 manifest를 제외한 1,672개 SHA-256/크기를 대조했고 불일치가 없었다. [입력 증거](verification/imported-baseline/production-refactor-20260920/provenance.json).

53개 Package.swift를 식별했다. 활성/지원 manifest 48개를 평가하고 5개 tools6.4 held manifest는 별도 환경 gate로 유지한다. package dependency·실제 source import·composition root와 핵심 public 호출/상태/I/O 경로를 확인했다. 모든 SDK 내부 코드나 모든 파일의 모든 줄을 읽고 증명했다는 뜻은 아니다.

검증 환경은 Linux x86_64, Swift 6.2.1이다. 기존 Core/Runtime/Hub/Agent/Knowledge 기능은 실제 재실행으로 회귀 확인했다. 입력의 이전 검증 보고는 `verification/imported-baseline`으로 분리했다.

## 3. 아키텍처 판단

`LanguageModelCore`는 값/계약, `ModelRuntime`은 run admission/종료, `ModelSession`은 대화 commit, `ModelExecutorStore`는 host configuration별 재사용, `LocalBackend`는 resident 최종 해제의 소유자다. 이름이나 actor 수가 비슷하다는 이유로 합치면 안 된다. 각자가 소유하는 상태가 다르다.

Account/Text/Image는 실제 외부 의존 경계이므로 별도 package가 타당하다. Text와 Image가 Account를 공유하는 것은 인증 공유이지 실행 종속이 아니다. Agent approval/effect journal, ASK canonical receipt, image artifact publication은 서로 다른 transaction domain이다. 하나의 성공값으로 합치지 않는다.

production graph에 새로운 강제 integration은 넣지 않았다. source bundler는 선택되지 않은 optional nested package·MCP·ASK·다른 provider를 제외한다. `MigrationHold`는 활성 dependency가 아니지만 아직 공개 API 대체가 검증되지 않아 전체 archive에서 보존했다.

## 5. 실제 수정

### R01 — producer → SSE → transport completion

`ChatGPTModelClient`가 기존 `ModelClientWithOwnedInvocation`을 구현한다. `generate`는 owned invocation을 소비하고 join한다. 기존 `stream`은 유지한 projection이다. `onStarted`는 validation 이후, 인증/catalog/I/O 앞에서 한 번 호출한다.

SSE producer는 transport invocation을 소유한다. 성공·HTTP 오류·parser 실패·취소 모두 transport 완료를 기다린다. 401을 위로 넘기기 전에 이전 attempt를 drain하므로 refresh/re-dispatch가 이전 연결 종료와 겹치지 않는다.

Account의 bounded JSON 소비와 Image wire도 동일 transport handle을 사용한다. 공통 `consuming` 경계는 정상/오류/취소 뒤 join하며 완료 대기 중 취소를 성공값으로 반환하지 않는다.

### R02 — 실제 HTTP에서 관측한 redirect crash

기존 순서와 같은 `invalidate/cancel → redirect completionHandler(nil)` 경로에서 FoundationNetworking의 redirect callback 상태 assertion으로 프로세스가 종료됐다. [실제 실패 로그](verification/imported-baseline/production-refactor-20260920/regressions/redirect-callback-before.log).

redirect callback은 먼저 nil로 거절한다. 거절된 응답을 정상 서비스 데이터로 노출하지 않고 task 완료 경계에서 오류를 마감한다. 실제 서버 request 기록으로 redirect target과 invalid-config 요청이 전송되지 않았음을 확인했다.

### R03 — task 완료와 session 종료를 모두 확인

Apple의 계약상 강제 invalidation 알림만으로 task 종료를 증명할 수 없다. task cancellation 뒤 graceful session invalidation을 요청하고, 순수 `ChatGPTTransportCompletionState`가 두 receipt를 모두 확인해야 waiter를 재개한다. 두 callback의 순서가 반대이거나 중복돼도 조기 완료하지 않는다.

일반 request 실패는 events로 전달한다. local completion을 증명하지 못한 injected transport는 wait port로 실패하며 Text는 기존 `ModelExecutorDrainFailure`로 Runtime에 전달한다. 오류를 idle/안전 재시도로 바꾸지 않는다.

### R04 — 독립 source 패키징

`tools/package-closure.py`가 Swift의 실제 manifest 평가 결과로 local dependency closure를 구한다. 새로운 실행 layer나 제품 dependency가 아니다. manifest·pin·lockfile·소스·리소스는 다시 쓰지 않는다. 경로 탈출/symlink/manifest 변경/기존 ZIP 덮어쓰기를 거절한다.

8종 source bundle을 생성했고 9개 packaging 테스트와 실제 공통 추출본 test/외부 consumer build/run을 검증했다. ChatGPT Text/Image bundle은 source/dependency integrity까지 검증하며 Apple 실행을 주장하지 않는다. [패키징 계약](PACKAGING.md).

## 6. 호환성·보존·변경 의미

기존 public stream/generate, provider pin, account origin/인증 retry policy, tool proposal, Agent 승인/효과 원장, ASK actionID/receipt, borrowed 수명, MigrationHold를 보존했다. 새 public error code나 자동 재생성/fallback은 추가하지 않았다.

**custom transport의 관리형 사용 조건은 강화됐다.** 기존 stream-only conformer는 source conformance와 직접 stream 호출을 유지하지만 Account/Text/Image에 주입하려면 invocation을 구현해야 한다. 미구현 default는 I/O 전에 기존 invalidConfiguration으로 실패한다. 임의 stream의 EOF를 no-op completion으로 감싸 성공을 만들어 주지 않는다. 바이너리 ABI·외부 소비 앱 source compatibility는 지원 Apple 빌드가 필요하다.

## 7. 검증 결과와 의미

[최신 실행표](verification/README.md)가 수치/명령/로그의 정본이다. 44개 wire 테스트는 기존 22개에 새 lifecycle/실제 HTTP 22개를 더한 것이다. 같은 44개를 10회 반복했고 고유 440개 테스트로 계산하지 않는다. 모델 producer 전체용 회귀 3개는 full Apple 모듈 gate에 추가했지만 이 환경에서는 실행되지 않았다.

실제 URLSession 검증: success, concurrent/idempotent completion wait, canceled waiter의 drain, 한 request 취소와 다른 request 격리, redirect 거절, Content-Length/cumulative size 초과, truncated peer disconnect, UTF-8 split SSE, 반복 재사용, dispatch 전 취소/invalid limit.

controlled gate 검증: EOF보다 늦은 native settlement, parser/401 오류보다 먼저 drain, completion 실패의 보존, image drain 중 취소, task/session receipt 도착 순서·중복. 이는 동시성 계약 증거이지 실제 ChatGPT 모델 응답 증거가 아니다.
