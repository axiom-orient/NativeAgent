# Quality Checklist

## 공통
- [ ] 피사체/장소/음식의 정체성이 요청과 일치한다.
- [ ] 프롬프트가 요구하지 않은 텍스트·로고·워터마크가 없다.
- [ ] 문화적 장식이나 브랜드 요소가 자동 추가되지 않았다.
- [ ] 스타일 효과가 내용 변경보다 우선하지 않는다.
- [ ] 변수 미지정 값을 모델이 과도하게 창작하지 않았다.

## 이미지 필요 프롬프트
- [ ] 인물/캐릭터 identity가 유지된다.
- [ ] 음식·그릇·오브젝트 개수와 상대 배치가 유지된다.
- [ ] 포즈/시점/크롭/랜드마크 geometry가 불필요하게 바뀌지 않는다.
- [ ] 불명확한 영역은 보수적으로 단순화되었다.

## 텍스트 전용 프롬프트
- [ ] 사용자가 제공한 장소/피사체/장면만 사용했다.
- [ ] 지리·광원·재질·스케일이 내부적으로 일관된다.
- [ ] 장면의 핵심 피사체와 시각적 위계가 명확하다.
