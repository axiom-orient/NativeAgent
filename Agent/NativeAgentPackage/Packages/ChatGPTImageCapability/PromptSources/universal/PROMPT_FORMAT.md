# Prompt Format

모든 정본 프롬프트는 다음 계약을 따른다.

## 1. Metadata
- `id`: 정본 ID
- `mode`: `REFERENCE_IMAGE_REQUIRED` 또는 `TEXT_ONLY`
- `category`: 사용 영역

## 2. 목적
프롬프트가 바꾸는 것과 보존하는 것을 한 문장으로 정의한다.

## 3. 입력
필수/선택 입력을 분리한다.

## 4. 범용 프롬프트
공통 순서는 다음과 같다.
1. 작업 선언
2. 입력 권위/생성 규율
3. 보존해야 할 내용
4. 적용할 스타일/메커니즘
5. 배경/텍스트/출력 정책
6. 금지 조건

## 5. 선택 변수
변경 가능한 제어값만 `UPPER_SNAKE_CASE`로 노출한다. 특정 제품명·도시명·인물명은 기본값에 넣지 않는다.

## 6. 실패 기준
모델 출력 평가에 직접 사용할 수 있는 관찰 가능한 조건으로 쓴다.

## 공통 원칙
- 이미지 변환: **content preservation > style intensity**
- 텍스트 생성: **prompt variables > model invention**
- 불명확한 세부: 창작보다 단순화
- 텍스트: exact text 미제공 시 생성 금지
- 장식: 사용자 의도에 없는 문화적/브랜드적 장식 자동 추가 금지
