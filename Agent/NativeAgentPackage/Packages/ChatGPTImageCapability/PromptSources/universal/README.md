# Universal Image Prompt Set

검토된 이미지 prompt source를 바탕으로 **브랜드·특정 장소·특정 인물에 종속되지 않는 19개 범용 프롬프트**를 제공하는 canonical set이다.

## 구조

- `reference-image-required/` — 업로드 이미지가 **필수**인 변환/정체성 보존 프롬프트 13개
- `text-only/` — 첨부 이미지 없이 텍스트 변수만으로 동작하는 생성 프롬프트 6개
- `PROMPT_FORMAT.md` — 전체 프롬프트가 공유하는 구조와 작성 규칙
- `SOURCE_ANALYSIS.md` — prompt set을 구성한 설계 근거
- `QUALITY_CHECKLIST.md` — 사용/검증 체크리스트
- `VERIFICATION.md` — 패키지 정적 검증 결과

## 핵심 설계

1. **입력 권위 명시** — 이미지 변환은 업로드 이미지를 identity/geometry의 source of truth로 취급한다.
2. **스타일과 내용 분리** — 스타일 변경이 피사체·장소·음식·구도 재설계로 번지지 않게 한다.
3. **브랜드 비의존** — 특정 스튜디오, 앱, 모델명, 특정 도시명에 결박된 표현을 제거했다.
4. **텍스트 안전성** — 정확한 문자열이 제공되지 않으면 임의 글자/로고/워터마크를 생성하지 않는다.
5. **실패 기준 명시** — 각 프롬프트가 무엇을 실패로 간주하는지 함께 정의한다.
6. **변수화** — 변경 가능한 값은 `UPPER_SNAKE_CASE` 변수로 분리한다.

## 사용법

원하는 canonical `.md` 파일의 `범용 프롬프트` 코드 블록을 복사한 뒤 `선택 변수`를 채운다. 이미지가 필요한 프롬프트는 먼저 기준 이미지를 첨부한다.
