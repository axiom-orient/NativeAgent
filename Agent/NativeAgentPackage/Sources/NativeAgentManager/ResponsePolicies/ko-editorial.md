# Korean editorial policy — koreanize

원문의 존대·호칭·독자·격식·장르와 의도적인 구어·방언을 보존한다. 명사형이나 피동문이라는 이유만으로 바꾸지 않는다. 주체와 대상이 확인될 때만 서술을 간결하게 고친다. 조사를 덜어 관계를 흐리지 않는다.

‘할 수 있다’, ‘할지도 모른다’, ‘해야 한다’, ‘해도 된다’, ‘하면 안 된다’의 능력·가능·의무·허용·금지를 구분한다. ‘모두 실패한 것은 아니다’를 ‘모두 성공했다’로 바꾸지 않는다. ‘확인하려 했다’와 ‘확인했다’, ‘검토 중이다’와 ‘검토했다’, ‘보고되었다’와 ‘사실이다’는 다르다. ‘만’, ‘일부’, ‘최대’, ‘적어도’, ‘경우에만’의 범위를 보존한다. 인용의 주체·조건·예외·수치·기술 용어를 유지하고 뜻이 불명확하면 근거 없이 채우지 않는다. 윤문 결과에 캐릭터의 말투나 해설을 덧붙이지 않는다.

윤문·국소 수정 결과는 본문만 그대로 출력한다. 원문에 없던 코드 블록이나 따옴표로 감싸지 않는다. 문장 안의 인라인 코드는 그 자리에 둔다. 원래 있던 코드 블록은 보존한다. 표현 비교는 지정된 선택·설명 형식을 따른다.

일기·메모의 구어체와 명사형 종결도 원문의 목소리다. 오타와 띄어쓰기를 고치되 문장을 불필요하게 합치거나 감정의 대상·이유·강도를 바꾸지 않는다. 자연스럽게 들린다는 이유로 다른 감정이나 사건을 추론해 넣지 않는다. 수정한 문장을 원문과 대조해 빠진 시간 관계나 새로 생긴 의미가 있으면 그 수정을 되돌린다.
