# 日本語の推敲方針

原文の「です・ます」「だ・である」、敬語の対象、話者、読者、方言を保ちます。丁寧さの統一を理由に、引用、会話、地の文を同じ文体にしません。

## 確認項目

- 「できる」「かもしれない」「はずだ」「ようだ」「そうだ」「なければならない」「なくてもよい」「てはいけない」は機能が異なります。能力・可能性・推測・伝聞・義務・許可・禁止を保ちます。
- 「とは限らない」と「ではない」、「すべてではない」と「一つもない」を区別します。限定の「だけ」「しか」「少なくとも」「最大」を削りません。
- 「ている」「てきた」「ていた」「てしまった」「ようとした」で、継続・変化・完了・意図の違いを保ちます。「確認できた」を単なる事実の断定にしません。
- 長い連体修飾や「の」の連続は、修飾先が同じと確認できる場合にだけ整理します。省略された主語を推測で補いません。属性の所有者や代名詞の指示先は、原文内の説明・用例で確定できる場合だけ明示します。
- 「検討を行う」は文脈により「検討する」にできますが、「検討する予定だ」は実施済みにしません。「ことができる」の「こと」だけを冗長扱いして可能を消しません。
- 「により」「ため」「一方」「そこで」の因果・手段・対比・時間関係を保ちます。受身は責任主体や焦点を変えずに直せる場合だけ変更します。
- カタカナ語の数で機械的に置換しません。API、ハンドラ、トレースバックなどの分野用語と、一般語の意味を混同しません。
- 読点や同じ文末の反復は、係り受け・説明の明瞭さ・ジャンルから判断します。語尾の変化を目的に断定の強さを変えません。
- 原文の固有名詞、数字、引用、コード内の日本語コメントも保護します。英語の段落を勝手に翻訳しません。
- 説明とコードに矛盾が見えても、推敲で意味を合わせません。修正には別の事実確認が必要です。依頼された監査では矛盾の箇所だけを指摘します。

## 最小対

| 原文 | 変更候補 | 判定・理由 |
|---|---|---|
| 必ず成功するとは限りません。 | 成功しません。 | 部分否定→全面否定 |
| 保存できるようにしました。 | 保存しました。 | 能力の実装→保存の実行 |
| 調査を行いました。 | 調査しました。 | 適切: 文脈と敬体が同じなら可 |
| 部長がご確認になりました。 | 部長を確認しました。 | 行為者と対象、尊敬の変更 |
| 接続が切れたそうです。 | 接続が切れました。 | 伝聞→直接の断定 |

「改善」と「改良」は何をどう良くするか、「確認」と「検証」は求める証拠から選びます。辞書上の類義語でも常に交換可能ではありません。
